概念

Score Function

— ∇log p(x)，把"密度增大方向"逐点指出的向量场。

定义 · $s(x) := \nabla_x \log p(x)$。对 $x$ 求梯度（不对参数）。
公式 · 归一化常数 $Z$ 对 log 求导 = 0，所以不需要算 $Z$。
易错 · score ≠ 密度本身；只决定方向，丢失归一化。

名字来自统计学家 Stein，不是"分数"。Vizuara L6 强调它是统一框架：

「Score-based perspective unifies VAE, diffusion, Langevin in a single cohesive framework.」—— Vizuara L6 #9

训练里 $\epsilon_\theta(x_t, t)$ 在期望意义上就是在估 score（差一个 schedule 系数）。

几何 + DDPM 等价

$\nabla \log p$ 处处指向密度更高的方向。前向扩散后：

$$\nabla \log p_t(x_t) = -\frac{1}{\sqrt{1-\bar\alpha_t}}\, \mathbb{E}[\epsilon | x_t]$$

所以 $\epsilon_\theta = -\sqrt{1-\bar\alpha_t} \cdot s_\theta$ —— 同一个东西两种参数化。

红箭头处处指向模 mode——不变量是 score 总指向密度更高的方向。

1D Gaussian

$p(x) = \mathcal{N}(0, 1)$, $\log p = -x^2/2 + \text{const}$. $s(x) = -x$. 在 $x = 2$，score = −2（指向 0）。

常见误区

  1. "知 score 就能采样"。反例：沿 score 走 = 寻峰；要采样必须 + 噪声（Langevin）。
  2. "score 给密度"。反例：归一化常数 $Z$ 丢失，不能算 likelihood（除非 PF-ODE）。
  3. "所有空间都准"。反例：流形外 score 几乎没定义——naive Langevin 高维失败的根源。
