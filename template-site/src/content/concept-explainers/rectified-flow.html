概念

Rectified Flow

— 多轮 reflow 把 FM 弯曲轨迹拉直，一步采样能出图。

定义 · 反复用上一轮模型采的 $(x_0, \hat x_1)$ 对重训 FM。
公式 · 同 FM loss，但数据对来自上轮模型采样。
易错 · FM 不保证轨迹直；reflow 才显式拉直。

CMU L10 讨论 distillation 思路：

「Train a new model such that one step replaces what used to take multiple steps. Loss comparison with the 500 time step. Hey yes, very very good.」—— CMU L9 #2-3

核心问题：FM 训完后积分的轨迹仍曲——marginal velocity 在 $(x_0, x_1)$ pair 交叉时取期望，方向被"平均"。

Reflow 算法

  1. 普通 FM 训出 $v_\theta^{(1)}$。
  2. 用 $v_\theta^{(1)}$ 从 $x_0 \sim \mathcal{N}$ 采得 $\hat x_1$。
  3. 新对 $(x_0, \hat x_1)$ 无歧义——再 FM 训 $v_\theta^{(2)}$，轨迹更直。
  4. 2-3 轮足够。

训直后一步采样：$\hat x_1 = x_0 + v_\theta^{(k)}(x_0, 0)$。SD3、InstaFlow、Hyper-SD 都基于此。

左弯右直——不变量是端点不变，只是轨迹路径变直。

常见误区

  1. "一次 reflow 就够"。反例：2-3 轮明显提升；再多边际递减。
  2. "= distillation"。反例：RF 重训 base 拉直；distillation 不动 base。
  3. "训直后步数无关紧要"。反例：1 步质量比多步略低。
