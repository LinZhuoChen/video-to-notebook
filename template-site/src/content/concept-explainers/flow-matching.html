概念

Flow Matching

— 直接训 ODE 速度场把噪声变数据，loss 是简单 MSE。SD3、SORA 都用。

定义 · 学时变向量场 $v_\theta(x, t)$，ODE $dx/dt = v_\theta$ 把噪声流到数据。
公式 · 直线 FM: $\mathcal{L} = \mathbb{E}[\|v_\theta(x_t, t) - (x_1 - x_0)\|^2]$，$x_t = (1-t)x_0 + tx_1$。
易错 · 训完后轨迹未必直；直线插值给的是条件速度。

CMU L5 讲师"灵光乍现"：

「Why don't we just do linear interpolation of the two things? Same noise, same data. This is literally the only thing stopping us from full matching. Class is over.（笑）」—— CMU L5 #2, #5

训练目标：采 $x_1, x_0, t$；合成 $x_t = (1-t)x_0 + tx_1$；让 $v_\theta(x_t, t)$ 估 $x_1 - x_0$；MSE。

FM 比 DDPM 简洁在哪

  • 无 schedule：直接选插值。
  • 无 ELBO：MSE 不来自变分。
  • 无 score：学 velocity（线性关联 score 但概念独立）。
  • 任意路径：直线、OT、diffusion path 都行。

直线 + 端点——不变量是直线情况下速度 $x_1 - x_0$ 不随 t 变。

样本 loss

$x_0=0.2, x_1=1.8, t=0.6 \Rightarrow x_t = 1.16$. ground-truth $v = 1.6$. 设 $v_\theta = 1.4$. loss = $0.04$.

常见误区

  1. "训完轨迹直"。反例：marginal velocity 在 mode 交叉处弯；要 rectified flow 显式拉直。
  2. "不能 likelihood"。反例：CNF + change-of-variables 可算。
  3. "FM = RF = CM"。反例：递进——FM 基础、RF reflow 拉直、CM 蒸馏一步。
