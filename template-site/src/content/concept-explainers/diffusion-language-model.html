概念

Diffusion Language Model

— 用扩散范式取代自回归做语言生成；LLaDA / DiffuLLaMA / SEDD 是代表。

定义 · LM 解码器是离散扩散过程；并行预测被 mask 的 token。
公式 · 训练用 MDLM 加权 CE 或 SEDD score-entropy。
易错 · 同规模 PPL 略输 ARM；真正卖点是 infilling + 并行解码 + self-correction。

Vizuara《Diffusion LM from Scratch》整个课程围绕这个概念。Dr. Raj 在 L1 直接致敬 Karpathy：

「Karpathy 反复问 — why isn't diffusion the default option for language?」—— Vizuara L2

Vizuara 在 L17 给出 Colab 实操："H100 GPU is much faster. If you don't have Colab Pro, start with T4 - budget mode runs only 2,000 steps."

真正卖点（不是 PPL）

  1. 原生 infilling：填中间和填首尾同一算法。
  2. 任意顺序生成：先 confidence 高的填。
  3. 并行解码：每 step 预测所有 mask 位置（throughput 5-10x）。
  4. Self-correction：填错可 re-mask 再填。

两 bar——不变量是 diffusion LM 的 forward 次数与序列长度解耦。

常见误区

  1. "已追上 ARM"。反例：仍输 PPL；LLaDA 某些 benchmark 追平不等于整体 SOTA。
  2. "必然 SOTA"。反例：scaling 验证未现；可能像 Bayesian NN 一样长期"理论优雅但工业小众"。
  3. "训练快"。反例：每 batch 要采 mask + forward + 加权 CE——单 step 比 ARM 慢一点。
