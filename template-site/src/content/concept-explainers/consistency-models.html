概念

Consistency Models

— 蒸馏 PF-ODE 得到函数 f(x, t)，让轨迹上每点都映到同一端点 x₀。

定义 · $f_\theta(x_t, t)$ 满足 $f(x_t, t) = f(x_{t'}, t') = x_0$ 对同条 PF-ODE 轨迹。
公式 · loss = $\|f_\theta(x_t, t) - f_{\theta^-}(x_{t-\Delta t}, t-\Delta t)\|^2$。
易错 · 需要 pre-trained PF-ODE（或独立 CT 训）。

CMU L10 chunk #2-3：

「Suppose we already have a pre-trained diffusion model. We do a loss comparison with the 500 time step. Hey yes, very very good.」—— CMU L9

核心想法：PF-ODE 上同条轨迹所有点对应同一个 $x_0$。CM 显式学这个端点映射。

训练（CD）

  1. 采 $x, t$；合成 $x_t$。
  2. 用 PF-ODE solver 算 $x_{t-\Delta t}$。
  3. loss = $\|f_\theta(x_t, t) - f_{\theta^-}(x_{t-\Delta t}, t-\Delta t)\|^2$。

边界 $f(x_0, 0) = x_0$ 用 skip-connection 硬 code。

采样

一步 $\hat x_0 = f(x_T, T)$；或多步精修（zigzag）2-4 步质量更高。LCM 让 SD 实时 4 步出图。

红箭头从轨迹各点指向 $x_0$——不变量是 $f$ 对同条轨迹返回同一端点。

常见误区

  1. "不需要 base diffusion"。反例：CD 必须有；CT 可从头但训得稍弱。
  2. "一步比多步好"。反例：多步精修明显高于一步。
  3. "= distillation 别名"。反例：CD 是 distillation 的一种；CT、progressive distillation 是别的思路。
