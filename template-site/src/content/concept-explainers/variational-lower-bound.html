概念

Variational Lower Bound

— ELBO；VAE / diffusion / flow matching 共同的训练目标。

定义 · $\log p_\theta(x) \geq \mathbb{E}_{q(z|x)}[\log p(x, z) - \log q(z|x)] = \mathrm{ELBO}$。
公式 · 拆分：$\mathrm{ELBO} = \mathbb{E}[\log p(x|z)] - D_{\text{KL}}(q(z|x) \| p(z))$。
易错 · 最大化 ELBO 同时提升 $\log p(x)$ 和压紧 gap——两件事都好。

Vizuara Dr. Raj 用"传送猫"作直觉：

「想算 p(x)——一只猫的概率。但 p(x) is intractable，因为算它要做积分。这就像把猫从地球传送到火星——你不可能把每个原子都传过去，太多了。所以找一个 L always ≤ p(x)，最大化 L，p(x) 也跟着顶上去。」—— Vizuara L8 #11-12

Jensen 推导

$\log p(x) = \log \int p(x, z) dz = \log \int q(z|x) \frac{p(x, z)}{q(z|x)} dz$（Kelly "the greatest trick"）。Jensen ($\log$ 凹)：

$$\log p(x) \geq \mathbb{E}_{q(z|x)}\!\left[\log \frac{p(x, z)}{q(z|x)}\right] = \mathrm{ELBO}$$

gap = $D_{\text{KL}}(q \| p_\theta(\cdot|x))$。

拆成 重建 − KL

$$\mathrm{ELBO} = \mathbb{E}_q[\log p(x|z)] - D_{\text{KL}}(q(z|x) \| p(z))$$

VAE 损失就是 negative ELBO。

蓝 ELBO 顶绿 log p——不变量 ELBO ≤ log p；两者一起上升。

简化算

$p(x|z) = \mathcal{N}(z, 1), p(z) = \mathcal{N}(0, 1), q(z|x) = \mathcal{N}(0.5, 1), x=1$. 采 $z=0.5$. 重建 = $\log \mathcal{N}(1; 0.5, 1) \approx -1.04$；KL = $\frac{1}{2}(\mu^2) = 0.125$. ELBO ≈ $-1.17$.

常见误区

  1. "ELBO = −loss"。反例：通常对，但实现里 loss = recon + β·KL，β 可调。
  2. "gap 固定"。反例：gap 随 q 变化，最大化 ELBO 间接逼近真后验。
  3. "扩散 ELBO 太多项不能用"。反例：DDPM 简化成 L_simple MSE。
