Image Generation

— 从噪声 / prompt 采样生成图像；2020 后 diffusion 接管这一任务。

定义 · 训练 $p_\theta(x)$ 或 $p_\theta(x|y)$，从中采样新图。
公式 · 评估：FID（分布相似）、CLIPScore（prompt fidelity）、IS（多样 + 质量）。
易错 · 任务名，不是单一方法；diffusion 当前主流。

CMU 10799 Lecture 7（"Guidance & Controllable Generation"）整堂讨论 conditional image generation 的工程范式。讲师明确：所有现代 SOTA 模型（SD、DALL·E 2/3、Imagen、SD3、Flux）都用 diffusion + CFG。

方法路线对比

方法代表

VAEVQ-VAE（重建模糊）
ARDALL·E 1（推理慢）
DiffusionSD, DALL·E 2/3, Flux（SOTA）

为什么 diffusion 赢

  • 训练极稳（MSE，无 mode collapse / Nash equilibrium）
  • mode 覆盖好（迭代采样）
  • 可控性强（CFG、ControlNet、LoRA）
  • scaling 友好（DiT）

方块从噪声到清晰——不变量："从已知 prior 采样 + 通过模型映射 → 新数据" 是所有 generative 方法的共同框架。

常见误区

  1. "FID 低 = 好图"。反例：FID 衡量分布距离，对 prompt fidelity 无知。CLIPScore + FID 一起看。
  2. "diffusion 永远比 GAN 慢"。反例：LCM 让 SD 4 步出图，接近 GAN 速度。
  3. "image gen 只是娱乐"。反例：医学影像、自动驾驶 sim、3D 建模、科学可视化都用。
