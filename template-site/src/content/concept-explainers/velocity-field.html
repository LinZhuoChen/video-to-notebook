概念

Velocity Field

— 时变向量场 v(x, t)，定义 ODE dx/dt = v(x, t)。

定义 · $v: \mathbb{R}^d \times [0, 1] \to \mathbb{R}^d$，每点每时给一个箭头。
公式 · $dx/dt = v_\theta(x, t)$，积分得轨迹。
易错 · velocity ≠ score；通过 schedule 系数相关但不同概念。

CMU L11 (Luma 客座) 直接 visualize：

「The ground truth velocity field exists. These trajectories can be seen as blue lines. ultimately the loss comes down to a simple L2 loss——extremely stable and scalable.」—— CMU L10 (Luma Linqi Zhou)

训练里 $v_\theta$ 是网络的输出对象；MSE 让它逼近 ground-truth velocity。

从 v 到轨迹

$$x(t) = x_0 + \int_0^t v(x(s), s) ds$$

数值积分用 Euler、Heun、RK4 等 solver。DDIM 是 Euler、CNF 用 adaptive RK45。

velocity 和 score

$v(x, t) = -\sigma_t s(x, t) + \text{drift}_t$（Gaussian 路径）。所以 score 网络可作 velocity 网络用，区别在训练目标。

箭头网格——不变量是粒子轨迹由 $v(x, t)$ 唯一决定。

手算 1D ODE

$v(x, t) = 1 - x$. $x_0 = 0, \eta = 0.5$. $x_{0.5} = 0 + 0.5(1) = 0.5$. $x_1 = 0.5 + 0.5(0.5) = 0.75$. 逼近 1。

常见误区

  1. "velocity 总指向数据"。反例：多模态时可转向。
  2. "velocity = v-prediction"。反例：v-pred 是 DDPM 参数化技巧，定义不同。
  3. "velocity 大 = 采样快"。反例：步数取决于 ODE 总积分时间（T=1）+ solver order。
