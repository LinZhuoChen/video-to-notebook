18. Latent Diffusion 与视频扩散

CMU L11 是 Luma AI 的 Linqi (Alex) Zhou 来做客座。chunk #2 他直接展示 Luma 最新视频生成模型 R3 的 demo——"we show some samples from our latest video model R3"。chunk #5 强调"L2 loss is extremely stable and scalable"，chunk #6 说扩散模型 suffer from "ODE simulation error and slow inference"。这一章用 Luma 视角讲 latent diffusion + 视频。

18.1 像素 diffusion 为什么贵

512×512×3 = 786,432 像素。U-Net 每层都要处理这么大张量；attention 是 $O(N^2)$。消费级硬件根本跑不动。这是为什么 DALL·E 2 / Imagen 都先在低分辨率扩散、再 cascade 超分。

18.2 Latent Diffusion (Rombach 2022)

核心思路：用 VAE 压缩到 latent，扩散在 latent 上做。

18.3 关键工程细节

  • VAE 必须单独预训冻结。联合训会让 VAE latent 退化。
  • 压缩率 $f = 8$ 是甜点。$f = 16$ 重建质量崩。
  • VAE 是有损的 —— latent diffusion 质量上限 = VAE 重建质量。SD3 升级 VAE 到 16 通道就是为此。
  • 文本通过 cross-attention 注入（CLIP / T5 编码 prompt → 注入每层 K/V）。

18.4 视频扩散（Luma 视角）

Linqi Zhou (chunk #2-5)：

「视频是更夸张的高维数据。我们 visualize 这个 process on a simple 2D graph——左边噪声、右边数据，blue lines = trajectories。ground-truth velocity field 通过 conditional flow matching 学到。L2 loss is extremely stable and scalable to large number of [parameters]. 但 diffusion models naturally suffer from ODE simulation error and slow inference——这是 Luma 内部一直在优化的方向。」

Video diffusion 架构：

  1. Video VAE：3D 卷积 + 时间下采，把视频压成 spatiotemporal latent。
  2. Diffusion backbone：DiT 扫 3D patches（spatial × temporal）。
  3. 采样：DDIM / flow matching 都行；CFG 同样适用。

Sora、Runway Gen-3、Kling、Veo、Luma R3 全是这套。

🟡 教材外补充：视频 diffusion 的核心挑战不是架构而是 (1) 数据稀缺（高质量长视频 ≪ 图像）、(2) 长时一致性、(3) attention $O(N^2)$ 在 $N = THW$ 下爆炸。Sora 用 patch sampling + truncated attention 才训得起。
本章要记住的三件事（讲师亲口给的）
  • Latent diffusion = VAE 压缩到 latent + diffusion 在 latent 上；开销降 ~64×。
  • Luma R3 用 conditional flow matching + L2 loss——"extremely stable and scalable"。
  • 视频 = spatiotemporal latent + DiT；Sora / Veo / R3 同一架构。
