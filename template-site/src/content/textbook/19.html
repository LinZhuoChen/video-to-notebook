19. 离散扩散：在 token 上加「噪」

CMU L12 chunk #0-7 讲师从"现在我们学了 distillation / consistency / flow maps，但 these are all on the continuous side" 切入——离散世界完全不同。chunk #2 提到 "Anthropic 的人跟我说他们 ICML 2024 有这方面的论文"；chunk #3 列出 "molecules or DNA" 是离散扩散的关键模态之一。这一章按 D3PM 框架讲离散扩散的"加噪"是什么。

19.1 为什么 Gaussian 不行

语言数据是 token id $\in \{1, \dots, V\}$。给整数加连续噪声：

$$\tilde x = x + \epsilon, \quad \epsilon \sim \mathcal{N}(0, 1)$$

得到 4.7、−2.3——不对应任何 token。强行四舍五入丢失信息；embedding 空间加噪声试过通常很差。

19.2 D3PM：用转移矩阵代替 Gaussian

Austin et al. 2021 统一框架。每步前向：

$$q(x_t = j \mid x_{t-1} = i) = [Q_t]_{ij}$$

$Q_t \in \mathbb{R}^{V \times V}$ 是 stochastic matrix。$Q_t$ 选择决定"噪声"含义：

$Q_t$ 类型语义谁用
Uniform小概率换成任意其他 tokenD3PM uniform
Absorbing概率 $\beta_t$ 换成 [MASK]MDLM / LLaDA / SEDD
Gaussian-id换成附近 id（仅有序词表）少用

19.3 Absorbing diffusion 胜出

语言任务上 absorbing (mask) 一骑绝尘，原因：

  • MASK = "this position is undecided"——和 BERT MLM 对齐。
  • 训练 = 动态 mask rate 的 BERT，可直接复用 transformer 实现。
  • 采样直观：从全 MASK 开始逐步填回。

19.4 训练 + 采样

训练：采 t → 每个 token 独立以概率 $\alpha_t$ 替换为 [MASK] → 模型预测被 mask 的 token → cross-entropy on masked positions。下一章 MDLM 给精确 loss 形式。

采样：从全 [MASK] 开始 → 每步模型预测所有 mask 位置 → 选 top-k confidence 填回 → 反复。

🟡 教材外补充：
  • 讲师 chunk #4-6 也讨论了"continuous diffusion on embedding"作为替代——把 token 嵌入到连续空间再扩散。但效果通常不如 absorbing。
  • 离散扩散和连续扩散数学骨架不同：连续 = SDE + score；离散 = CTMC + ratio。下一章 SEDD 是统一尝试。
本章要记住的三件事
  • token 上加 Gaussian 没意义——用转移矩阵 $Q_t$ 定义"加噪"。
  • Absorbing (mask) diffusion 在语言任务上 SOTA——训练 = 动态 mask rate 的 BERT。
  • 离散扩散适用于 token、molecules、DNA 等所有"离散结构"数据。
