13. Flow Matching：直接回归速度场

CMU L5 整堂课的"灵光乍现"时刻——讲师在 chunk #2 说"Why don't we just do linear interpolation of the two things?" —— 这一问开启了 flow matching。Chunk #4-7 紧接着展示推导：固定 $x_0$ (noise) 和 $x_1$ (data)，沿直线 $x_t = (1-t)x_0 + tx_1$ 走，瞬时速度恒为 $x_1 - x_0$。"This is literally the only thing stopping us from full matching"——loss 就是 MSE。

13.1 推导（讲师在白板上）

「Same noise, same data. 选 0.25 progress 那个点：$x_{0.25} = 0.75 \cdot x_0 + 0.25 \cdot x_1$。
沿这条线的瞬时速度 = $x_1 - x_0$（讲师说 "displacement"）。
这就是literally the only thing 我们要学的。Class is over.（笑） Hey, no, not really.」

形式化训练目标：

$$\mathcal{L}_{\text{FM}} = \mathbb{E}_{t, x_0, x_1}\!\big[\|v_\theta(x_t, t) - (x_1 - x_0)\|^2\big], \quad x_t = (1-t)x_0 + tx_1$$

13.2 比 DDPM 简洁在哪

  • 无 schedule：DDPM 要选 $\beta_t$；FM 直接选插值路径。
  • 无 ELBO：MSE 不来自变分；Conditional FM 证它等价 marginal FM。
  • 无 score：学 velocity，和 score 通过线性公式相关但概念独立。
  • 任意路径：直线 / 二次曲线 / OT path 都行；DDPM 是 FM 的一种特殊路径选择。

13.3 为什么 SD3 / SORA 都换了 FM

理由具体
训练稳MSE 直接学速度场，loss landscape 干净
少步采样直线路径下 ODE 几乎直，10-20 步出图
扩展自然视频 / 3D 只要定义 $(x_0, x_1)$ 就行
🟡 教材外补充：FM 训完后采样轨迹未必是直线（marginal velocity 在 mode 交叉处会弯）；Rectified Flow 通过 reflow 显式拉直。
本章要记住的三件事（讲师亲口给的）
  • FM = 直接学 ODE 速度场，loss 是 MSE。讲师原话："this is literally the only thing stopping us."
  • 直线路径下瞬时速度恒为 $x_1 - x_0$ —— 训练目标极简。
  • SD3、SORA、各种现代 diffusion 都迁到 FM；DDPM 还教，但工业主流已变。
