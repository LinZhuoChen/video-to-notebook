7. DDPM 全貌

Vizuara《Principles of Diffusion Models》Lecture 3 讲 DDPM 理论，Lecture 4 讲 DDPM Practical——butterflies 数据集 + 完整代码。讲师开场原话："The last lecture focused on theory. Now we'll take a practical example and see how DDPM is applied." 这一章把两讲拼起来，再加 DDPM 原论文（Ho et al. 2020，32k 引用）的 $L_{\text{simple}}$ 简化。

7.1 三件套（讲师的拼图）

  1. 前向过程 $q(x_t|x_{t-1})$：零参数 Gaussian 链。每步：$x_t = \sqrt{1-\beta_t}\, x_{t-1} + \sqrt{\beta_t}\, \epsilon$。Dr. Raj 用 α² + β² = 1 的约束保证方差守恒。
  2. 神经网络 $\epsilon_\theta(x_t, t)$：通常是 U-Net 或 DiT。输入污染过的 $x_t$ 和时间 $t$，输出对噪声的估计。
  3. 反向采样：从 $x_T \sim \mathcal{N}(0, I)$ 开始，每步从 $p_\theta(x_{t-1}|x_t)$ 采，迭代 T 次回到数据。

7.2 关键魔法：$L_{\text{simple}}$

朴素 ELBO 展开是 $T$ 项 KL——Kelly 老师当场说过 "This chain of chaos is elegant in theory but doesn't work well, it's too complicated"。Ho et al. 2020 做了两步简化：

  1. 把网络重参数化为预测噪声 $\hat\epsilon$（而不是预测均值 $\mu$）。两者等价。
  2. 丢掉 $t$ 相关系数。论文实测发现丢掉后采样质量反而更好。
$$\boxed{\;L_{\text{simple}} = \mathbb{E}_{x_0, t, \epsilon}\!\left[\|\epsilon - \epsilon_\theta(\sqrt{\bar\alpha_t} x_0 + \sqrt{1-\bar\alpha_t}\epsilon,\ t)\|^2\right]\;}$$

用大白话："给一张污染过的图，让网络猜出加进去的噪声"。就是 regression。

7.3 训练代码（讲师 Vizuara L7 的实现思路）

for x0 in dataloader:                                  # butterflies, 32x32
    t = torch.randint(1, T+1, (x0.shape[0],))          # 每张图独立 t
    eps = torch.randn_like(x0)                         # 独立噪声
    alpha_bar = alphas_cumprod[t]                      # 查 schedule
    x_t = sqrt(alpha_bar) * x0 + sqrt(1-alpha_bar) * eps  # 一次性合成
    eps_hat = model(x_t, t)                            # 一次 forward
    loss = F.mse_loss(eps_hat, eps)                    # MSE
    loss.backward(); optimizer.step()

三行核心算法。不需要把 1000 步真的跑出来——靠 第 4 章 的跳步公式。

7.4 采样：T 步反向迭代

x = torch.randn(shape)                                  # x_T ~ N(0, I)
for t in reversed(range(1, T+1)):
    eps_hat = model(x, t)
    mu = (x - beta_t / sqrt(1-alpha_bar_t) * eps_hat) / sqrt(alpha_t)
    z = torch.randn_like(x) if t > 1 else 0
    x = mu + sqrt(beta_t) * z                            # x_{t-1}
return x                                                # x_0

这就是 ancestral sampler——慢，因为 T = 1000 次 forward。DDIM、DPM-Solver 等都是为了把它压到 20-50 步。

7.5 历史 + 引用规模

Dr. Raj 特地点名："这篇 DDPM 论文（Ho et al. 2020）有 32,000 引用，是 diffusion 工业化最重要的一篇。在它之前 diffusion 概念早就有（Sohl-Dickstein 2015），但没人证明它能产生 realistic images——是 Ho et al. 把它做出来的。"

🟡 教材外补充：
  • 为什么 $\epsilon$-prediction 比 $x_0$-prediction 稳：目标量 $\epsilon \sim \mathcal{N}(0, I)$ 对所有 $t$ 同尺度；$x_0$ 在 $t$ 大时几乎要从纯噪声"凭空猜"，梯度乱跳。详见 概念页。
  • FID 数字（CIFAR-10 32×32）：DDPM 3.17；同期 GAN ~5；Improved DDPM 2.94；EDM 1.9。10 天 V100×8 训完。
本章要记住的三件事（讲师亲口给的）
  • DDPM = 前向（写死）+ U-Net（预测噪声）+ 反向迭代采样。α² + β² = 1 保证方差守恒。
  • $L_{\text{simple}}$ = ELBO 经过"ε-参数化 + 丢系数"得到的极简 MSE on noise。
  • Vizuara L4 用 butterflies (32×32) 完整跑了一遍代码；Ho et al. 2020 已有 32k 引用，是 diffusion 工业化的起点。
