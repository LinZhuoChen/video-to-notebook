16. DDIM：去掉随机性的采样器

CMU L7 开场（Lecture 7 - Guidance）讲师回顾："Last time we learned DDIM which is like a fast sampling technique"——把它视作 DDPM 的"加速器"。DDIM 不重训模型，只换采样器，把 1000 步压到 50 步、还能 image inversion。这一章按"同一网络 / 不同 sampler"的角度讲清楚。

16.1 关键洞察

Song et al. 2020 证明：同一个训好的 $\epsilon_\theta$，反向过程未必是 DDPM 的 Markov 链。存在一族 non-Markovian 反向链，它们的 marginal 分布都和 DDPM 一致。Generalized step：

$$x_{t-1} = \sqrt{\bar\alpha_{t-1}}\hat x_0 + \sqrt{1-\bar\alpha_{t-1}-\sigma_t^2}\hat\epsilon + \sigma_t z$$
  • $\sigma_t = \sqrt{\tilde\beta_t}$ → DDPM ancestral（最大随机）
  • $\sigma_t = 0$ → DDIM（完全确定）

16.2 跳步可行的原因

当 $\sigma_t = 0$，反向 step 是 PF-ODE 的一阶 Euler 离散化。跳步 = 用粗时间网格做 ODE 积分。ODE 在粗网格上仍能积分得不错——这是 50 步质量不掉的几何原因。

16.3 副产品：确定性 + 双射

DDIM 是确定性 → $x_T \leftrightarrow x_0$ 双射（数值精度内）。两个能力：

  • Image inversion：给真实图反向跑得 $x_T$，改 prompt 再 forward → 做编辑（SDEdit、ControlNet 都靠这个）。
  • Latent interpolation：两个 $x_T$ 做 slerp，对应图像平滑插值。
🟡 教材外补充：DDIM 是 PF-ODE 的一阶离散化。DPM-Solver、Heun（EDM 默认）是高阶离散化，质量更好。SD 默认 sampler（DPM++ 2M、Karras）都是这条线的衍生。
本章要记住的三件事
  • DDIM 不重训，只换 sampler——把 DDPM ancestral 换成 PF-ODE 的 Euler 离散化。
  • 跳步 = 粗时间网格 ODE。50 步质量已够用。
  • 确定性 + 双射 = image inversion + latent interpolation 的基础。
